DATABASE TOOLS & UTILITIES INDEX

OVERVIEW
--------
This directory contains comprehensive database inspection, query, and export
tools for the Advise Workbench application. All tools are Python scripts that
work with the SQLite database (advise_workbench.db).

================================================================================
AVAILABLE SCRIPTS
================================================================================

1. quick_db_stats.py
   ✓ PURPOSE: Quick overview of database statistics
   ✓ SPEED: < 1 second (fastest)
   ✓ OUTPUT: Bar chart with record counts per table
   ✓ BEST FOR: Daily checks, CI/CD monitoring
   ✓ COMMAND: python quick_db_stats.py

2. check_all_db_records.py
   ✓ PURPOSE: Comprehensive audit of all database records
   ✓ SPEED: < 2 seconds
   ✓ OUTPUT: Detailed information organized by table
   ✓ BEST FOR: Full inspection, verification, debugging
   ✓ COMMAND: python check_all_db_records.py

3. db_sql_queries.py
   ✓ PURPOSE: 16 pre-built SQL queries with joins
   ✓ SPEED: < 2 seconds
   ✓ OUTPUT: Query results in tabular format
   ✓ BEST FOR: Relationships, specific lookups, analysis
   ✓ COMMAND: python db_sql_queries.py

4. db_export_utility.py
   ✓ PURPOSE: Export records to CSV and JSON formats
   ✓ SPEED: < 3 seconds
   ✓ OUTPUT: Files in db_exports/ directory
   ✓ BEST FOR: Backup, external analysis, sharing
   ✓ COMMAND: python db_export_utility.py

5. quick_check_db.py
   ✓ PURPOSE: Check conversation summaries specifically
   ✓ SPEED: < 1 second
   ✓ OUTPUT: Conversation summary details
   ✓ BEST FOR: Idle detection monitoring
   ✓ COMMAND: python quick_check_db.py

IDLE DETECTION INFO

CURRENT SETTINGS
  Timeout: 600 seconds (10 minutes)
  Enabled: Yes (for all projects)
  Status: Active

HOW TO TRIGGER SUMMARY
  1. Send message in conversation

  ✓ Recorded decisions
  ✓ FSM state
  ✓ Trigger type (idle_10min or session_closed)

================================================================================
TROUBLESHOOTING
================================================================================

Problem: "Migration not applied yet"
Solution: alembic upgrade head

Problem: Database is locked
Solution: Check for running processes, kill if necessary

Problem: Export folder not found
Solution: mkdir db_exports && python db_export_utility.py

Problem: Script errors
Solution: Check .env file has valid JWT_SECRET (≥16 chars)

Problem: No data showing up
Solution: Run check_all_db_records.py first to verify records exist
