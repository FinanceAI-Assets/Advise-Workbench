## Data Types Captured in Deliverables

### 1. Skill Output Payloads (LLM-Generated)

**What's Captured:** Structured content generated by LLM for each deliverable type

#### PPTX Skill Output
```json
{
    "pptx_data": {
        "slides": [
            {
                "title": "Opening Slide",
                "body": "Content for the slide...",
                "speaker_notes": "Speaker notes go here...",
                "layout_type": "title_only|title_content|2_column|content_only",
                "elements": [
                    {
                        "type": "bullet_list|image|chart|table|text_box",
                        "content": "...",
                        "properties": {"indent": 0, "font_size": 14}
                    }
                ]
            }
        ],
        "metadata": {
            "deck_title": "Q4 Sales Deck",
            "slide_count": 12,
            "theme": "classic|editorial",
            "audience": "executives",
            "created_at": "2026-10-30T14:30:00Z"
        }
    }
}
```

**Size:** Typically 50–150 KB (text-based, structured JSON)

**Where Stored:**
1. **In-Memory** (During render)
   - Type: Python dict
   - Scope: Request lifetime
   - Thread-safe: No (single-threaded render)

2. **Database** (`RunTask.output_json`)
   - Table: `run_tasks`
   - Column: `output_json` (Text)
   - Indexed: No
   - Query: `SELECT output_json FROM run_tasks WHERE run_id = $1 AND id = 'draft_pptx'`

3. **Filesystem** (Debug/Archive)
   - Path: `workspace/{project_id}/runs/{run_id}/artifacts/pptx_data.json` (optional)
   - Size: ~80 KB
   - Retention: Per run policy

## Storage Locations

### 1. Database (PostgreSQL/SQLite)

#### run_tasks Table
```sql
CREATE TABLE run_tasks (
    id VARCHAR(64),
    run_id VARCHAR(64),
    output_json TEXT NOT NULL,  -- ← Skill output (pptx_data, docx_data, xlsx_data)
    PRIMARY KEY (id, run_id)
);
```

**Query to Retrieve Skill Output:**
```sql
SELECT output_json 
FROM run_tasks 
WHERE run_id = 'run_abc123' 
  AND id IN ('draft_pptx', 'draft_docx', 'draft_xlsx');
```

**Example Output:**
```json
{
    "id": "draft_pptx",
    "output_json": "{\"pptx_data\": {\"slides\": [...]}}"
}
```

---

#### run_events Table
```sql
CREATE TABLE run_events (
    id INT AUTO_INCREMENT PRIMARY KEY,
    run_id VARCHAR(64),
    event_type VARCHAR(64),      -- 'artifact_rendered', 'quality_checked'
    payload TEXT NOT NULL,       -- Quality signals, branding applied, metrics
    created_at DATETIME
);
```

**Query for Quality Signals:**
```sql
SELECT payload 
FROM run_events 
WHERE run_id = 'run_abc123' 
  AND event_type = 'artifact_rendered'
ORDER BY created_at DESC;
```

---

#### project_brands Table
```sql
CREATE TABLE project_brands (
    id VARCHAR(64) PRIMARY KEY,
    project_id VARCHAR(64) UNIQUE,
    primary_color VARCHAR(16),
    font_family VARCHAR(64),
    font_size_base INT,
    logo_url VARCHAR(1024),
    company_name VARCHAR(255),
    footer_text VARCHAR(255),
    created_at DATETIME,
    updated_at DATETIME
);
```

**Query to Load Branding:**
```sql
SELECT * FROM project_brands WHERE project_id = 'proj_123';
```

## Retention Periods

### Deliverable-Specific Retention

#### Artifact Files
**Default:** No automatic cleanup
**Policy:** Managed via `EngagementMeta.retention_days`

```sql
-- Example retention policy
SELECT retention_days FROM engagement_meta 
WHERE project_id = 'proj_123';

-- Example: retention_days = 90
-- Action: Delete artifacts older than 90 days from run completion
DELETE FROM workspace/{project_id}/runs/{run_id}/artifacts/*
WHERE created_at < NOW() - INTERVAL 90 DAY;
```

**Typical Values:**
- Short-lived (drafts): 7 days
- Standard (approved decks): 90 days
- Long-term (compliance): 365 days
- Indefinite (never delete): NULL

---

#### Skill Output (RunTask.output_json)
**Retention:** Indefinite (no automatic cleanup)
**Rationale:** Small (~80 KB per task), queryable for audit/rerun

---

#### Quality Signals (RunEvent.payload)
**Retention:** Indefinite (immutable event stream)
**Rationale:** Audit trail for quality assessment decisions

---

#### Branding Context (ProjectBrand)
**Retention:** Indefinite (actively maintained)
**Update:** Manual (when company rebrands)

---

#### Tempfiles (Logo, intermediate images)
**Lifetime:** Render phase only
**Auto-cleanup:** Python `tempfile` module (deleted on close)

## Complete Data Flow: From Skill Output to File

### Step 1: Skill Execution → Payload Generation

```
LLM Output (claude-opus-5-5)
    │
    ├─ Model: claude-opus-5-5 (for quality)
    ├─ System Prompt: "Generate PPTX content..."
    ├─ Input Tokens: 8,200
    ├─ Output Tokens: 4,100
    │
    └─ Output JSON:
       {
           "pptx_data": {
               "slides": [
                   {"title": "...", "body": "...", "speaker_notes": "..."}
               ],
               "metadata": {...}
           }
       }
              │
              ▼ (Payload Validation)
       JSON schema check
       Required fields validation
       Sanitization (redact emails, wiki links)
              │
              ├─→ SUCCESS: Proceed
              └─→ FAILURE: Emit error event, abort
```

**Storage After Validation:**
```python
# Stored in memory
payload_dict = json.loads(llm_output)

# Persisted to database
run_task.output_json = json.dumps(payload_dict)
session.add(run_task)
session.commit()
```

### Step 2: Branding Resolution

```
DeliverableRegistry.get("pptx")
    │
    └─ PPTXDeliverable instance (singleton)
              │
              ▼
BrandingService.get_for_project(project_id, level)
    │
    ├─ Query ProjectBrand table
    │  └─ SQL: SELECT * FROM project_brands WHERE project_id = $1
    │
    ├─ Check runtime overrides (from run context)
    │
    ├─ Check skill overrides (from payload)
    │
    ├─ Load cached value (Redis or memory)
    │
    ├─ Merge hierarchy (Runtime > Skill > Project > Default)
    │
    └─ Return BrandingContext object
              │
              ▼
Flatten to dict
    _merge_branding_dict(branding)
    │
    ├─ primary_color: "#86BC25"
    ├─ secondary_color: "#E8007C"
    ├─ accent_light: "#EBF5D3"
    ├─ accent_dark: "#5A8A00"
    ├─ font_family: "Calibri"
    ├─ font_size_base: 11
    ├─ logo_url: "https://..."
    ├─ company_name: "Deloitte"
    ├─ footer_text: "Deloitte."
    └─ neutral_light, neutral_dark, text_primary, text_inverse
              │
              ▼ (Stored in memory)
       branding_dict = {...}
```

**Cache Behavior:**
```python
# Check cache first
cached = redis.get(f"branding:project:{project_id}")
if cached:
    return cached

# Load from DB if cache miss
branding = session.query(ProjectBrand).filter_by(project_id=project_id).first()
if not branding:
    branding = BrandingService.default_brand

# Cache for 24 hours
redis.setex(f"branding:project:{project_id}", 86400, branding.to_dict())
return branding
```

### Step 3: Logo Fetch (SSRF-Safe)

```
If branding.logo_url is set:
    │
    ├─ validate_url(url)
    │  ├─ Check for https:// (enforce HTTPS)
    │  ├─ Check against private IP blocklist
    │  └─ Validate domain (no localhost, 10.0.0.0/8, etc.)
    │
    ├─ safe_get(url)
    │  ├─ Timeout: 10 seconds
    │  ├─ Size cap: 10 MB
    │  ├─ Follow redirects: up to 5
    │  └─ Return: bytes
    │
    ├─ tempfile.NamedTemporaryFile(suffix=".png|.jpg")
    │  ├─ Write image bytes to temp file
    │  ├─ Keep file open for render phase
    │  └─ Auto-delete on close (no manual cleanup)
    │
    └─ Store tempfile path in memory
       temp_logo_path = "/tmp/...logo.png"
```

**Storage:**
- **In-Memory:** Tempfile path (string)
- **On-Disk:** Temporary directory (auto-GC'd)
- **Cache:** Optional Redis cache of image bytes (1 hour TTL)

### Step 5: Render to File

```
PPTXDeliverable.render(payload, run_dir, branding)
    │
    ├─ Create Presentation() object
    │
    ├─ Configure slide dimensions
    │  ├─ Width: 13.333 inches
    │  ├─ Height: 7.5 inches
    │  └─ Standard widescreen aspect ratio
    │
    ├─ For each slide in payload["slides"]
    │  │
    │  ├─ Create slide from layout
    │  │  ├─ layout_type: "title_only", "title_content", "2_column"
    │  │  └─ prs.slide_layouts[layout_index]
    │  │
    │  ├─ Add title (if present)
    │  │  ├─ position: Inches(0.5, 0.5)
    │  │  ├─ text: slide["title"]
    │  │  ├─ font: Pt(44), Color(primary_color)
    │  │  └─ bold: True
    │  │
    │  ├─ Add body content
    │  │  ├─ Split content into shapes
    │  │  ├─ Add text, bullets, tables, images
    │  │  └─ Apply formatting per branding
    │  │
    │  ├─ Add speaker notes (if present)
    │  │  ├─ Split into chunks (15KB max per note)
    │  │  └─ Add to notes_slide
    │  │
    │  └─ Add elements (charts, images)
    │     ├─ Image: Embed from URL via safe_get
    │     ├─ Chart: Generate CategoryChartData
    │     └─ Style per branding palette
    │
    ├─ Apply core properties
    │  ├─ Title: payload["metadata"]["deck_title"]
    │  ├─ Author: "Advise Workbench"
    │  ├─ Keywords: "advise_workbench,pptx"
    │  ├─ Subject: "Process documentation"
    │  ├─ Created: datetime.now(IST)
    │  └─ Modified: datetime.now(IST)
    │
    ├─ Add footer to all slides
    │  ├─ Text: custom_footer_text or company_name
    │  ├─ Position: Bottom-right
    │  ├─ Font: font_family, Pt(8)
    │  └─ Color: primary_color
    │
    └─ Save to file
       output_path = workspace_path(project_id) / "runs" / run_id / "artifacts" / "deck_001.pptx"
       prs.save(str(output_path))
              │
              └─→ Binary OOXML file written to disk (2–50 MB)
```

**In-Memory Objects Created:**
```python
prs = Presentation()                          # ~50KB in memory
# + slide objects, shape objects, text objects
# Total: ~100KB per slide during assembly

# After save(), Presentation object released (GC)
del prs  # or let it go out of scope
```

### Step 6: Extract Quality Signals

```
extract_quality_signals(artifact_path)
    │
    ├─ Run PPTX QA checks
    │  ├─ Count slides: len(prs.slides)
    │  ├─ Compare to MAX_RENDERED_SLIDES (25)
    │  ├─ Check completeness
    │  │  ├─ Title presence: slide has text_frame
    │  │  ├─ Body presence: slide has content
    │  │  └─ Speaker notes: text length > 0
    │  │
    │  ├─ Assess design
    │  │  ├─ Color consistency
    │  │  ├─ Font usage
    │  │  └─ Layout adherence
    │  │
    │  └─ Run evidence gate
    │     ├─ Check for citations/sources
    │     ├─ Flag unsubstantiated numeric claims
    │     └─ Score: passed|warning|failed
    │
    ├─ Calculate scores
    │  ├─ completeness_score: 0–1.0
    │  ├─ design_score: 0–1.0
    │  ├─ structure_score: 0–1.0
    │  └─ overall_score: weighted average
    │
    └─ Return: Quality dict
       {
           "completeness_score": 0.92,
           "design_score": 0.88,
           "structure_score": 0.95,
           "quality_flags": [...],
           "evidence_gate": {...}
       }
```

**Storage:**
```python
# Memory (during extraction)
signals = {
    "artifact_type": "pptx",
    "slide_count": 12,
    "completeness_score": 0.92,
    "quality_flags": [...]
}

# Persist to database
event = RunEvent(
    run_id=run_id,
    event_type="artifact_rendered",
    payload=json.dumps({
        "output_type": "pptx",
        "file_path": str(artifact_path),
        "quality_score": 0.92,
        "quality_flags": signals["quality_flags"]
    }),
    created_at=utcnow()

session.add(event)
session.commit()

# Optional: Save to filesystem
qa_report_path = workspace_path(project_id) / "runs" / run_id / "qa_report_pptx.json"
qa_report_path.write_text(json.dumps(signals))
```

```
              │
              ▼
2. SKILL_OVERRIDE
   └─ Source: Skill output payload
   └─ Lifetime: Render scope
   └─ Example: {"pptx_data": {...}, "branding_override": {"primary_color": "#E8007C"}}
              │
              ▼
3. PROJECT_CUSTOM (from ProjectBrand table)
   └─ Source: Database
   └─ Lifetime: Project lifetime
   └─ Example: ProjectBrand.primary_color = "#86BC25"
              │
              ▼
4. INGESTED_DESIGN_SYSTEM
   └─ Source: Wiki/OneDrive (if set)
   └─ Lifetime: Project lifetime
   └─ Example: ProjectBrand.design_system_json = {...}
              │
              ▼
5. DELOITTE_DEFAULT
   └─ Source: Code constant
   └─ Lifetime: App lifetime
   └─ Example: ColorPalette(primary="#86BC25", ...)
```

**Resolution Code:**
```python
def get_for_project(project_id, level=None):
    # Level 1: Runtime override
    if level == BrandingLevel.RUNTIME_OVERRIDE:
        return runtime_context.branding

    # Level 2: Skill override
    if skill_output.get("branding_override"):
        return BrandingContext.from_dict(skill_output["branding_override"])

    # Level 3: Project custom (from DB)
    row = session.query(ProjectBrand).filter_by(project_id=project_id).first()
    if row:
        return BrandingContext.from_db_row(row)

    # Level 4: Ingested design system (if set)
    if row.design_system_json:
        return BrandingContext.from_design_system(json.loads(row.design_system_json))

    # Level 5: Default
    return BrandingService.default_brand()
```

**Cache Key:** `branding:project:{project_id}`

**TTL:** 86400 seconds (24 hours)

- Hard invalidation: `redis.delete(key)` after update

- Check: `if redis_available() else memory_fallback[key]`

## Memory Management During Render

### Memory Lifecycle

```
Request Start
    │
    ├─ Load payload from DB      (~80 KB)
    ├─ Load branding from cache  (~10 KB)
    ├─ Fetch logo tempfile       (~2–5 MB)
    │
    └─→ Total: ~2–5 MB in memory
              │
              ▼
Render Phase
    │
    ├─ Create Presentation obj   (~50 KB base)
    ├─ Add slides (12 × ~8 KB)   (~96 KB)
    ├─ Add shapes, text          (~50 KB)
    ├─ Add logo image (in memory)(~2–3 MB)
    │
    └─→ Total: ~2–3.5 MB
              │
              ▼
Write to Disk
    │
    ├─ prs.save(filepath)        (2–50 MB file size)
    │
    └─→ Presentation object released
              │
              ▼
Quality Extraction
    │
    ├─ Reload .pptx from disk    (~2–50 MB)
    ├─ Parse OOXML              (~100 KB memory)
    ├─ Extract signals          (~50 KB)
    │
    └─→ Parse object released
              │
              ▼
Request End
    │
    ├─ Tempfile deleted          (auto via context manager)
    ├─ Payload dict GC'd         (out of scope)
    ├─ Branding dict GC'd        (out of scope)
    │
    └─→ Memory released
```

### Memory Safety

**No Leaks:**
- Payloads: Ephemeral (request scope)
- Branding: Reference counted (auto GC)
- Logo tempfile: Context manager (auto-delete)
- Presentation object: Goes out of scope (auto GC)

**Thread Safety:**
- Singleton registry: Protected by RLock
- Per-request data: No shared state

**Resource Limits:**
- Max artifact size: 50 MB (typical)
- Max in-memory during render: ~5 MB
- Max tempfile size: 10 MB (logo size cap)

## Multi-Render Path Architecture

### Render Path Options

**PPTX has two render paths:**

#### Path 1: Artifact-Tool Renderer (Modern)
- **Location:** `_render_with_artifact_tool()`
- **Backend:** External artifact-tool binary
- **Features:**
  - Advanced layout planning
  - Better spacing/typography
  - Faster on large decks
  - Optional (falls back if unavailable)

#### Path 2: Python-PPTX Renderer (Fallback)
- **Location:** `_render_with_python_pptx()`
- **Backend:** python-pptx library
- **Features:**
  - Pure Python (no external deps)
  - Well-tested, stable
  - Generates layout signals
  - Text density warnings

**Selection Logic:**
```python
def render(self, payload, run_dir, branding):
    # Try artifact-tool first
    artifact_path = self._render_with_artifact_tool(payload, run_dir, branding)
    if artifact_path:
        return artifact_path
    
    # Fallback to python-pptx
    return self._render_with_python_pptx(payload, run_dir, branding)
```

**Configuration:**
```env

figure_vocab_v2_enabled=true

docx_storyline_spine_enabled=true

```
